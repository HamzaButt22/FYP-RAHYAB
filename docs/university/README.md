## Before you submit

1. Open each file in Word.
2. Add the Riphah logo to the cover (the original templates had it; it isn't in this repository).
3. Check the formatting the templates ask for: Times New Roman 12 pt, justified.
4. Ask the supervisor to sign the change record and the approval page.
5. Template-04 v1.5 changes the scope from the submitted v1.4 (class 8–12 instead of 9–12; Big Five and questionnaires removed). Get supervisor approval first, and record it in "List of Faculty Proposed Changes".
