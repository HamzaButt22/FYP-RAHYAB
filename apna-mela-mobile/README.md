# Apna Mela: Android app (Expo / React Native)

This is the mobile version of the Apna Mela career-interest game (RahYaab FYP). It plays in **landscape** and works offline: answers are saved only on the phone. Everything is in English.

It is a rebuild of the desktop pygame game with the same content and the same rules:

- **Same content:** the same 20 What cards, 30 How cards, 10 diary items, dialogues, art, music and sounds.
- **Same scoring:** the same RIASEC scoring rule (picks, then Loved-it mean, then stall visits).
- **Big Five stays separate:** it is consent-gated and stored in its own record. It is never shown and never used for career ideas.
- **No timing data:** no response time or hesitation is recorded.

## 1. Run it on your phone with Expo Go (fastest)

**On the phone:**
1. Install **Expo Go** from the Play Store.
2. The app must support **SDK 58**; keep it updated.

**On your PC:**
1. Install **Node.js LTS** (20 or newer) from nodejs.org.
2. Open a terminal in this folder and run:
   ```bash
   npm install
   npx expo start
   ```
3. A QR code appears. In Expo Go, tap **Scan QR code** and scan it. The phone and the PC must be on the **same Wi-Fi**.

**Troubleshooting:**
- **The phone can't connect (school or office Wi-Fi often blocks this):** use `npx expo start --tunnel` instead.
- **Windows blocks `npm` (Application Control):** run `node "C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js" install`, or ask IT to allow Node.js.

The first load takes a little longer because the images and music are copied to the phone.

## 2. Make an installable APK (for a pilot without a PC)

```bash
npm install -g eas-cli
eas login                      # free Expo account
eas build -p android --profile preview
```

When the build finishes, EAS gives you a link to download the `.apk`. Install it on any Android phone (allow "install unknown apps"). The `production` profile builds a Play Store `.aab` instead.

## 3. Checks

```bash
npm test            # 20 tests: content rules, RIASEC + Big Five scoring, a full 5-day game, saves, consent, crash repair
npm run typecheck   # TypeScript
npx expo export --platform android   # Android bundle
```

`tools/playthrough.py` drives a web build through the whole 5-day game at phone size (915 x 412) and screenshots every screen. The results are in `docs/screenshots/`.

## 4. What changed for mobile

| Area | Mobile behaviour |
|---|---|
| Layout | Designed on a 1280 x 720 canvas and scaled to any phone. Wide phones use the extra width. Tablets centre the play area. Camera cut-outs (safe areas) are respected. |
| Touch | Every button is at least 48 dp tall and has a press animation. You can tap a selected card again to confirm. Cards, hearts and the diary scale have large tap areas. |
| Smoothness | All animations run on the native driver: card deal, lifts, stamps, page turn, confetti, fireworks and character bob. Images are WebP, cached in memory. |
| Feedback | Haptic taps (can be turned off with **Vibration** in Settings). Sounds are AAC. Music fades between screens and pauses when the app goes to the background. |
| Android back | Back closes the top overlay. During play it opens Pause. On the main menu it asks before leaving. Back never quits a game by accident. |
| Screen | Landscape lock, immersive mode (system bars hidden), the screen stays awake. A "turn your phone" card appears in portrait. |
| Settings | Music and sound on/off with 4 volume steps, text size (3 steps), reduce motion, high contrast, vibration, research notes (with confirmation), and delete my data (two confirmations). |
| Privacy | No accounts, ads or analytics. The microphone permission is blocked in builds. Saves are separate records: profile, riasec, and bigfive (bigfive only with consent). Saves are written in order, and repaired if the app is killed mid-answer. |

## 5. Project layout

```
App.tsx                 fonts, splash, orientation, immersive mode, screen + overlay host
src/logic/              content.ts, session.ts, riasec.ts, bigfive.ts, storage.ts, rng.ts (pure TypeScript, tested)
src/app/                AppContext.tsx (navigation + flow rules), audio.ts, settings.ts, hooks.ts
src/ui/                 layout.tsx (scaling), kit.tsx (widgets), overlayLayers.tsx (fx + toasts), theme.ts, assets.ts
src/screens/            Menu, Story, Gameplay, Overlays, Results
src/data/               the same JSON content as the desktop game
assets/game/            WebP images, AAC audio and OFL fonts (from tools/convert_assets.py)
src/assets/registry.ts  generated by tools/gen_registry.py
```
